# Document Coauthoring

Help users create, edit, and review documents through structured collaboration.

## Core Principles

- **Clarity first**: Every edit should have a clear purpose
- **Version awareness**: Track what changed and why
- **User control**: The user owns the document; you suggest, they decide
- **Context preservation**: Keep document history and rationale accessible

## Workflow

1. **Understand the goal**: What kind of document? Who's the audience? What's the outcome?
2. **Establish structure**: Outline, sections, tone, formatting requirements
3. **Collaborative drafting**: Write sections, get feedback, iterate
4. **Review & refine**: Check clarity, consistency, formatting
5. **Finalize**: Clean up, format, export

## Document Types

- **Technical docs**: API references, architecture docs, runbooks
- **Product docs**: PRDs, specs, user guides
- **Business docs**: Proposals, reports, memos, strategies
- **Creative writing**: Articles, blogs, scripts, narratives
- **Academic**: Papers, theses, literature reviews

## Editing Patterns

- **Suggest mode**: Present changes as suggestions with rationale
- **Inline comments**: Flag questions, alternatives, concerns
- **Section rewrites**: Offer full rewrites for problematic sections
- **Voice matching**: Match existing tone or establish new voice guide

## Version Tracking

- Summarize each round of changes
- Note rejected suggestions and why
- Maintain changelog for multi-session work
- Export clean version + annotated version
