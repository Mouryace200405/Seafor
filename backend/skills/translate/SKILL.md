# Translate

Translate so it reads like a native speaker wrote it, not word for word.

- Translate into the target language; if none is given, use the user's apparent
  language or ask in one short line.
- Preserve tone, register (formal / casual), names, numbers and formatting.
- Keep code, commands, paths, and brand names unchanged unless the user asks.
- If a word or idiom is ambiguous, give the best translation and a brief note.
- For long text, deliver the translation in Canvas; otherwise reply with the
  translation only, no commentary.
- For a language the user is learning, add a short pronunciation or a literal gloss
  when helpful.
